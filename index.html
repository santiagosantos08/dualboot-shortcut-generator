IMPORTANT NOTICE: Generating or downloading these files is only part of the process. Setting up working desktop shortcuts, admin permissions, and shortcut parameters still requires manual configuration on both OS sides. Full step-by-step instructions are provided at the bottom of this page.
Regarding the 'Sticky' modes: when using 'Sticky Linux' or 'Sticky Windows' the pc will *always* go to that one, so if you decide to go with Sticky Linux and Windows needs to update and reboot, it will go to Linux in the middle of that, meaning you'll have to restart and enter the bios/boot menu. If you don't like that behaviour stick -pun intended- with Sticky last used (or bios default, it will always go to that one)

4. Manual Setup Instructions

Windows Setup:

  1. Save the generated PowerShell code into a file named linux_reboot.ps1 in a permanent folder.
  2. Place your chosen .ico image file in the same folder.
  3. Right-click linux_reboot.ps1 and select Send to -> Desktop (create shortcut).
  4. Right-click the new shortcut on your Desktop and open Properties.
  5. Change the Target field to:
    C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -NoExit -ExecutionPolicy Bypass -File "C:\path\to\your\linux_reboot.ps1"
  6. Click Advanced... and check the box for Run as administrator.
  7. Click Change Icon... and browse to select your .ico file.
  8. Move the shortcut to C:\ProgramData\Microsoft\Windows\Start Menu\Programs so it appears in your Start Menu.

Linux Setup:

  1. Save the generated Bash code into a file named windows_reboot.sh at the absolute path specified in section 2.
  2. Place your chosen .png icon at the absolute path specified in section 2.
  3. Make the script executable by running:
    chmod +x /path/to/windows_reboot.sh
  4. Save the desktop entry content into a file named windows_reboot.desktop in ~/.local/share/applications/
  5. If the application icon does not show up immediately in your application menu, log out and log back in.

5. Icon Resources & Tools

For the Win->Linux shortcut:
  • Public Icon Repo: You can find clean vector/PNG logos for Linux distros at simpleicons.org.
  • Converting PNG to ICO on Linux: If ImageMagick is installed, you can convert any PNG into a multi-resolution ICO file using:
    magick convert input.png -define icon:auto-resize=256,128,64,48,32,16 output.ico
    Otherwise you can use any online converter, since that .ico is needed for the Win->Lin shortcut and you probably don't have ImageMagick on Windows..
