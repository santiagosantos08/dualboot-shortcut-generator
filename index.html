Dual-Boot Reboot Script Generator

What's this site about? -> A way to make shortcuts that easily reboot from one OS to another when dual booting Windows and Linux. This skips waiting for Grub to show up (it's bootloader agnostic), also skips spamming f12. Works -only- for UEFI systems + works with secure boot (supported, not required).
It allows you to keep kernel-level anticheat like Riot Vanguard happy, because even if you were happy waiting for grub to select your OS, you might have discovered that Vanguard gets tripped if you chainload Windows after Grub.
Video demo and the post that originated this site

0. Create Necessary Directories

Before saving any scripts or icons, make sure to create the dedicated directories on both operating systems:

  • Linux: Create ~/scripts/winreboot (/home/YOUR_USERNAME/scripts/winreboot).
  • Windows: Create C:\scripts\linuxreboot
    • These are just recommended, you can use whatever, just make sure to replace the paths in the Linux .desktop file and the Windows shortcut later on if you decide to use a different one.. I just wanted to keep the site as minimal as possible to avoid decision fatigue on new users, adding customizable fields for this would've been trivial but also kinda made the process unnecesarily complex for people that don't care about it.

1. Boot Behavior Mode

Regular reboot refers to rebooting from the OS menu instead of using the shortcut, also automatic reboots due to updates or required by installing software.

2. Target Parameters

On Windows, open PowerShell as admin, then run 'bcdedit /enum firmware' (without the quotes) and input JUST whatever is in the description field for your Linux entry (will be something like Fedora, Ubuntu, Grub, etc) If you are not sure of this, open a terminal and run 'whoami' (without the quotes)

4. Icon Resources & Tools

For the Win->Linux shortcut:
  • Public Icon Repo: You can find clean vector/PNG logos for Linux distros at simpleicons.org.
  • Converting PNG to ICO on Linux: If ImageMagick is installed, you can convert any PNG into a multi-resolution ICO file using:
    magick convert input.png -define icon:auto-resize=256,128,64,48,32,16 output.ico
    Otherwise you can use any online converter, since that .ico is needed for the Win->Lin shortcut and you probably don't have ImageMagick on Windows..

5. Final Setup Instructions

Windows Setup:

  1. Save the generated PowerShell file linux_reboot.ps1 in C:\scripts\linuxreboot
  2. (optional) Place your chosen .ico image file in the same directory.
  3. Right-click linux_reboot.ps1 and select Send to -> Desktop (create shortcut).
  4. Right-click the new shortcut on your Desktop and open Properties.
  5. By default, the Target field will show:
    C:\scripts\linuxreboot\linux_reboot.ps1
    Change the Target field to:
    C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe -NoExit -ExecutionPolicy Bypass -File "C:\scripts\linuxreboot\linux_reboot.ps1"
  6. Click Advanced... and check the box for Run as administrator.
  7. (optional) Click Change Icon... and browse to select your .ico file.
  8. (optional) Move the shortcut to C:\ProgramData\Microsoft\Windows\Start Menu\Programs so it appears in your Start Menu.

Linux Setup:

  1. Save windows_reboot.sh and your chosen .png icon (e.g. win11.png) in ~/scripts/winreboot.
    Just like in the Windows->Linux one, the icon is optional, if you don't want one remove the 'Icon' line from the .desktop file
  2. Make the script executable by running:
    chmod +x ~/scripts/winreboot/windows_reboot.sh
  3. Save the desktop entry windows_reboot.desktop in ~/.local/share/applications/
  4. (optional) If the application icon does not show up immediately in your application menu, log out and log back in.
